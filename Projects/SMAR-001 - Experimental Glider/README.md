# SMAR-001 — Experimental Glider

## Objective

Design, simulate, build and test a small glider while investigating how aerodynamic design choices affect stability and performance.

## Research question

How do wing design and centre-of-gravity position affect the stability and glide performance of a small aircraft?

## Method

Research → Simulate → Design → Build → Test → Analyse → Improve

## Current phase

Research

## Status

🟡 In progress

## Folder structure

- `Research/` — background theory, references, literature
- `Calculations/` — aerodynamic and stability calculations
- `Designs/` — sketches, CAD, design iterations
- `Experiments/` — KSP and physical test plans and logs
- `Results/` — measured data, analysis, conclusions
